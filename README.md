# Botzone 双人德州扑克 (TexasHoldem2p)

## 项目概述

本项目是 Botzone 平台双人德州扑克游戏的开发框架，用于开发 AI Bot 参加比赛。

## 游戏规则

### 基本信息
- **游戏类型**: 无限注德州扑克 (No Limit Texas Hold'em)
- **玩家数量**: 2人
- **初始筹码**: 20000
- **小盲注**: 50
- **大盲注**: 100
- **比赛局数**: 50小局

### 牌局流程

一局完整的德州扑克包含4轮叫注：

| 阶段 | 英文名称 | 公共牌数量 | 下注顺序起点 |
|---|---|---|---|
| 翻牌前 | Preflop | 0张 | 大盲注下家 |
| 翻牌 | Flop | 3张 | 小盲注 |
| 转牌 | Turn | 4张 | 小盲注 |
| 河牌 | River | 5张 | 小盲注 |

### 下注操作

| 操作 | Response | 说明 |
|---|---|---|
| 弃牌 | -1 | 舍弃手牌，退出本局 |
| 全押 | -2 | 投入全部剩余筹码 |
| 跟注/过牌 | 0 | 跟注或不下注 |
| 加注 | >0 | 额外下注筹码数 |

### 牌型大小 (从大到小)
1. 同花顺 - 五张同花色连续牌
2. 四条 - 四张相同点数
3. 葫芦 - 三条 + 一对
4. 同花 - 五张同花色不连续牌
5. 顺子 - 五张连续不同花牌
6. 三条 - 三张相同点数
7. 两对 - 两组不同对子
8. 一对 - 一组对子
9. 高牌 - 无法组成以上牌型

### 牌面编码

| 牌号 | 牌面 | 编码规则 |
|---|---|---|
| 0-3 | 2 (四花色) | 牌号 % 4 = 花色 |
| 4-7 | 3 (四花色) | 牌号 // 4 + 2 = 牌值 |
| ... | ... | ... |
| 48-51 | A (四花色) | 0=红桃, 1=方块, 2=黑桃, 3=草花 |

## 交互协议

### Request (JSON格式)
```json
{
  "num_players": 2,
  "dealer_id": 0,
  "my_id": 1,
  "my_chips": 19800,
  "my_cards": [51, 23],
  "public_cards": [3, 8, 41],
  "history": [...],
  "hand": 3,
  "max_hand": 50,
  "total_win_chips": [1200, -1200],
  "total_win_games": [2, 1]
}
```

### Response
单个整数：-1(弃牌) / -2(全押) / 0(跟注/过牌) / >0(加注)

## Bot开发说明

1. Bot 需要读取标准输入的 JSON 数据
2. Bot 需要输出单个整数作为响应
3. 每步操作需在1秒内完成
4. 非法操作（超时、错误格式等）将被视为弃牌
